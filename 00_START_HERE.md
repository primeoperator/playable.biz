# PLAYABLE.BIZ — стартовый комплект для Claude

## Что здесь находится

- `MASTER_PROMPT.md` — основной промпт для работы в обычном Claude Chat.
- `source-materials/` — авторская концепция, исходные HTML-прототипы и визуальный референс.
- `existing-work/marketing-site/` — ранее созданный маркетинговый сайт с сохранёнными демо.
- `docs/` — стартовые документы состояния, допущений, дорожной карты и тестового статуса.

## ВАЖНО: загрузка в бесплатный Claude Chat

Этот ZIP нужен прежде всего для аккуратного хранения всего стартового проекта. Официальный список поддерживаемых типов документов Claude Chat не перечисляет ZIP как стандартный тип загрузки. Если интерфейс не позволяет прикрепить архив как читаемый файл, распакуйте его на компьютере и прикрепите поддерживаемые файлы по отдельности: `MASTER_PROMPT.md`, `source-materials/idea/prompt.txt`, HTML-файлы прототипов и сайта, PNG-референс и README.

Не отправляйте один ZIP и не предполагайте, что Claude прочитал его: в первом сообщении попросите Claude подтвердить фактически доступные файлы. Вложения в одном и том же диалоге можно использовать для продолжения работы. Для дальнейших контрольных точек скачивайте архивы и храните локально.

## Приоритет исходников

- `source-materials/prototypes/bakery-original.html` — исходный PIXEL BAKERY CRM. Не перезаписывать маркетинговым `index.html`.
- `source-materials/prototypes/realty-original.html` — исходный SPB REALTY TYCOON.
- `existing-work/marketing-site/index.html` — предыдущая версия маркетингового сайта.
- Демо внутри `existing-work/marketing-site/demos/` — копии прототипов, использовавшиеся в сайте.
- `source-materials/idea/prompt.txt` — описание концепции и масштабирования.

Секретов и реальных данных клиентов в комплекте быть не должно.
